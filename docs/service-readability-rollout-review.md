# 서비스 가독성 확장 검증 — 2026-09-23

## 적용
- 사무실청소를 포함한 서비스 34개와 안양 바닥왁스코팅 지역 페이지 1개.
- 공통 enhanced 스타일, ReadingParagraph 문장 배치, 목차 대상별 BackToContents.
- 긴 문장에 수동으로 검토한 의미 단위 breakAfter만 지정. 기존 원문 변경 없음.
- 프리미엄청소의 별도 메뉴와 ECOSORB 시험자료 section도 각각의 실제 목차에 맞춰 복귀 버튼 적용.

## 결과
- 프로덕션 빌드 성공, 50개 정적 페이지 생성.
- 기존 테스트 28개 통과.
- 35개 페이지 변경 전후 본문(공백 정규화), 링크, 이미지 src/alt, 제목, head 메타 태그, canonical, JSON-LD 일치.
- 메타 태그 삽입 순서는 빌드에 따라 달라질 수 있어 태그 전체를 정렬하여 비교. 값은 제외하지 않음.
- 새 복귀 버튼만 비교 대상에서 제외. 모든 목차 대상의 마지막 요소와 접근 가능한 링크 이름 검증.
- 브라우저에서 320/390/768/1280px 설정으로 35개씩 총 140회 가로 넘침 검사: 모두 없음. 스크롤바를 제외한 clientWidth는 각각 305/375/753/1265px.
- 대표 화면 시각 확인: 프리미엄청소 모바일 목차·견적 본문, 화재청소 PC 본문·고정 목차.
- 실제 메뉴 이동: 모바일 견적 section 상단 약 96px, PC 약 192px. PC 복귀 후 service-toc 포커스 확인.

자동 검사와 대표 화면 검증이며, 모든 페이지의 모든 구간을 수동으로 촬영한 것은 아님.
배포·커밋·푸시하지 않음.
