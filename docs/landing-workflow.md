## 단계별 지역 발행

안양 바닥왁스코팅 글을 기준으로, 앞으로 실제 자료가 확보된 `지역 + 서비스` 조합을 하나씩 계속 추가합니다. 같은 서비스라도 지역별 실제 공간·재질·오염·작업 판단과 현장 조건이 드러나게 작성하며, 지역명만 바꾼 복제 글은 발행하지 않습니다.

1. 관리자에서 서비스와 지역을 배정합니다. 현재 7개 큰 지역의 시·군·구 126개 범위를 유지합니다.
2. 조사 근거와 글을 검토합니다. 지역명만 바꾼 글이나 근거 없는 현장 실적은 발행하지 않습니다.
3. 제목·설명·H1·본문을 `src/lib/regional-pages.json`에 준비합니다. `reviewed: false`인 문서는 주소와 사이트맵에 공개하지 않습니다.
4. 실제 사진은 공개용으로 승인한 파일만 `public/images/`에, 영상은 `public/videos/`에 복사합니다. 관리자 원본 폴더와 이 공개 저장소는 별개입니다. 로컬 PC 경로나 비공개 업로드 주소는 쓰지 않습니다.
5. `media` 항목에 `type`(image/video), `src`, `alt`, `caption`을 지정합니다. 다른 지역의 참고 사진은 캡션에 명시합니다. 사진의 각도·메타데이터 변경을 새 현장의 근거로 사용하지 않습니다.
6. 검토 후 `reviewed: true`로 전환하고 빌드·미리보기를 확인한 뒤 실제 배포합니다. 같은 서비스+지역 주소를 중복 등록하면 빌드를 중단합니다. 기존 글을 개선할 때에는 해당 기록을 갱신합니다.
7. 실제 배포 URL의 정상 응답을 확인한 뒤에만 관리자 발행 이력에 기록합니다. 지역 배정·작성 완료·파일 생성은 공개 발행과 다릅니다.

2026-10-05 운영 오류 수정: 지역 문서와 공개 미디어의 파일 존재 여부는 개발 서버 시작·프로덕션 빌드 전에 검사합니다. 검토된 관리자 내보내기 문서는 이 단계에서 `src/lib/regional-imports.json`으로 묶습니다. 배포 서버의 요청 처리에서는 `content/regional`이나 로컬 `public` 파일을 다시 읽지 않습니다. 새 지역 자료를 추가한 뒤에는 준비 스크립트와 빌드를 실행하고 생성된 스냅샷도 함께 검토합니다. 메타 설명에는 특정 세 단어를 강제하지 않고 해당 사례와 상담 조건을 자연스럽게 담습니다.

로컬 검증 도구가 자식 프로세스 생성을 제한하는 환경에서는 `CHEONGSO_LOCAL_WORKER_THREADS=1`을 설정한 빌드로 스레드 워커와 TypeScript API 검사를 사용합니다. 타입 검사를 생략하지 않습니다. 이 환경변수가 없는 Vercel 빌드는 기존 기본값을 사용합니다. 서버 기반 회귀 테스트는 먼저 로컬 프로덕션 서버를 3101번 포트에 실행한 뒤 수행합니다.

메인 모바일 배경 영상은 `public/videos/hero-mobile.mp4` 한 개만 사용합니다. 기존 `hero-web.mp4`의 전체 42.84초 장면과 16:9 화면비를 유지하고, H.264/yuv420p·864×486·25fps·faststart로 인코딩했습니다. 미지원 환경에서는 포스터를 유지하며 대용량 원본을 모바일에서 다시 요청하지 않습니다. 원본 web/HD 파일과 PC 재생 경로는 유지합니다. 새 영상 생성 시 길이·화면비·전체 디코딩과 시작/중간/끝 화면을 검증하고 모바일에서 실제 재생을 확인합니다.

본문은 같은 Noto Sans KR의 가변 굵기를 사용하며 기존 400·500·700·900 표시를 유지합니다. 폰트별 중복 선언을 줄이고 기존 외부 CSS 캐시를 유지합니다. `inlineCss`는 운영 검증에서 홈 HTML과 gzip 전송 부담이 크게 늘었고 모바일 성능 향상을 확인하지 못해 사용하지 않습니다. 스타일 최적화는 빌드 후 본문·메타 정보 보존, 실제 화면, HTML 압축 크기와 운영 성능을 함께 확인합니다. 장식 폰트와 로고는 유지합니다.

현재 관리자에서 이 저장소로 자동 전송하거나, 배포 결과를 관리자에 자동 기록하는 연결은 구현하지 않았습니다. 관리자 내보내기 자료는 위 공개 문서 형식으로 검토·반영해야 합니다. 따라서 전국 소진 판정이나 다음 회차를 이 홈페이지가 임의로 해제하지 않습니다.

## 지역 범위와 대표 도메인

`src/lib/phase-regions.json`은 기존 관리자의 공식 지역 코드 자료 중 합의한 126개만 추렸습니다. 읍·면·동과 추가 시도 확대는 추후 결정에 따릅니다. 지역 데이터의 수집일·출처는 파일에 보존했습니다.

대표 주소 기본값은 `https://www.cheongso.co.kr`입니다. `SITE_URL`을 지정하더라도 apex `cheongso.co.kr`은 www 주소로 정규화해 canonical·사이트맵·실제 리디렉션 목적지를 일치시킵니다. 단순 예시 도메인으로 canonical을 바꾸지 않습니다.

## 회사 정보 관리

`src/lib/site-config.ts`에 확인된 업체 정보를 유지하고 연락 채널과 구조화 데이터가 같은 값을 참조하도록 합니다. 상담 내용 이메일 전송은 예약이나 견적 확정이 아닙니다. 실제 접수 범위를 바꿀 때는 화면 안내, API 동작과 오류 문구를 함께 검증합니다.

이 변경에는 AI 글·사진·영상 생성 API 호출이 없습니다. 검색 노출 결과는 이 구현만으로 보장하지 않습니다.
