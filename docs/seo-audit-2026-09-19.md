## 범위와 결론

사이트맵의 **43개 콘텐츠 주소**(기본 페이지 6, 서비스 36, 지역 페이지 1)를 실제 운영 HTML과 로컬 배포용 빌드에서 검사했다. 서비스 중 19개는 개별 랜딩 컴포넌트, 17개는 공통 랜딩 컴포넌트다. 모든 서비스가 최종 편집 완료 상태라고 가정하지 않았다. 특수청소·바닥시공·사업장청소를 중심으로 화면을 추가 확인했다.

수정 후 배포용 빌드의 자동 점검 항목은 43개 주소 모두 통과했다. 이는 주소·메타데이터·구조화 데이터·HTML 본문·내부 링크에 대한 기술 검사 결과이며, 검색 순위나 AI 답변 채택을 보장하는 점수가 아니다. 이번 변경은 로컬 검증본이며 운영 반영에는 별도 배포가 필요하다.

미완성 서비스의 문구·가격·사진을 새로 작성하지 않았고, 지역 페이지를 대량 생성하거나 기존 서비스에 일괄 noindex를 적용하지 않았다. 작업 시작 전에 있던 `src/components/service-pages/shared.tsx`의 사이드바 스크롤 수정은 별도로 보존했다.

## 남은 작업과 우선순위

1. **콘텐츠 최종 검토 시 표현 일치**: 나노코팅 랜딩은 포세린타일 바닥만 진행하고 유리·수전·상판은 제외한다고 안내한다. 공통 서비스 데이터는 유리·타일, 가격표는 포세린·폴리싱과 반영구 효과를 안내한다. 실제 제공 범위를 기준으로 세 곳을 맞춰야 한다. 이번에는 편집 중인 내용을 임의 확정하지 않았다. 시험성적서 설명도 실제 시험 대상·조건과 서비스 전체에 대한 표현이 일치하는지 최종 검토가 필요하다.
2. **성능 후속 측정**: 이번 검증본 배포 후 PSI를 다시 실행하고 LCP·전송량을 비교한다. 이후 이미지/영상 파생본으로 남은 용량을 줄인다. 모바일 접근성 대비 지적도 대상 색상과 화면을 확인하며 개별 보완한다.
3. **Local SEO 사실 확인**: 공개 가능한 실제 사업장 주소, 영업시간, 실제 방문 가능한 지역을 확정해야 LocalBusiness와 외부 업체 프로필을 일관되게 연결할 수 있다. 지역 데이터 허용 목록은 운영 지점이나 실제 출동망의 증거가 아니다. 별점·리뷰 개수·지점·지역 시공 실적을 만들어 넣지 않는다.
4. **지역 확장**: 현재 공개 지역 페이지는 안양 바닥왁스코팅 1개다. 기존 전국 지역 데이터만 유지했고 PENDING 코드도 이번에 검증 완료로 바꾸지 않았다. 실제 사례·지역별 조건·사진·검토가 준비된 지역부터 발행한다.
5. **실제 색인 확인**: www 사이트맵 제출 상태, URL 검사, 크롤링 오류, 검색 노출·유입을 Google/Naver 관리도구에서 확인한다. 인증 태그 존재와 인증/색인 완료는 다르다.
6. **메일 운영**: 입력·통신 오류는 이번에 처리했지만 장기간의 반복 발송 방지는 별도다. 트래픽에 따라 Vercel 방화벽 또는 공유 저장소 기반 제한을 적용해야 하며, 서버 인스턴스 메모리만으로 완전한 발송 제한을 보장하지 않는다.

## 검색·AI 최적화 적용 근거

- [네이버 JavaScript 검색 최적화](https://searchadvisor.naver.com/guide/seo-advanced-javascript): 핵심 내용이 원본 HTML에 있도록 보완했다.
- [Google LocalBusiness 문서](https://developers.google.com/search/docs/appearance/structured-data/local-business): 주소 없는 업체에 임의 주소를 만들지 않고 확인 가능한 Organization 정보를 제공한다.
- [Google 지원 메타 태그](https://developers.google.com/search/docs/crawling-indexing/special-tags): meta keywords는 Google 검색 순위·색인에 영향을 주지 않는다. 기존 분류용 키워드는 유지하되 태그 수를 성과로 설명하지 않는다.
- [Google 사이트맵 가이드](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap): 의미 있는 실제 콘텐츠 수정일과 빌드 시간을 구분했다.
- [OpenAI 크롤러 안내](https://developers.openai.com/api/docs/bots): 검색용 OAI-SearchBot, 사용자가 요청한 접근용 ChatGPT-User, 학습용 GPTBot의 역할을 구분한다.
- [Anthropic 크롤러 안내](https://support.claude.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler): Claude-SearchBot·Claude-User·ClaudeBot 이름을 반영했다.

기존 robots.txt의 `User-agent: *`도 수집을 허용하고 있었다. 이번 명시적 이름 정비를 과거 차단의 해제로 과장하지 않는다. JSON-LD는 보이는 내용과 맞아야 하며 FAQ 검색 특수표시나 AI 인용을 보장하지 않는다. 별도 AI 전용 파일이나 키워드 반복보다 정확한 본문·정상 URL·내부 링크·검증 가능한 회사/서비스 정보가 우선이다.
