# CheongSo

전국 청소 플랫폼

Next.js([App Router](https://nextjs.org/docs/app)) 기반 홈페이지입니다.

## Getting Started

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 에서 확인할 수 있습니다.

- 회사 정보(전화번호, 주소 등): `src/lib/site-config.ts`
- 서비스 카테고리: `src/lib/services-data.ts`
- 메인 페이지: `src/app/page.tsx`

## Deploy

[Vercel](https://vercel.com/new)에서 이 저장소를 import하면 바로 배포할 수 있습니다.
